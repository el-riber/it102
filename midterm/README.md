For this assignment I created a Math Pathway Advisor that checks whether a student’s most recent or highest math course meets the BAS Application Development requirement. 
I used JavaScript functions to organize the logic. The main function connects the entire process by calling getCourseNumber, checkEligibility, and displayResults. 
The getCourseNumber function validates the input and makes sure the student enters a real NSC math class. The checkEligibility function compares the class to the BAS requirement,
which is completing a QSR course in Calculus or Statistics. Finally, the displayResults function uses innerHTML to show the results directly on the page. 
I also added a list of math courses with their names and next steps based on the NSC Math Sequence chart. 
My goal was to make the tool easy to read and helpful for students who are trying to understand the math pathway for the BAS program.
